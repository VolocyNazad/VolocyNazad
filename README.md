I work on reusable libraries, developer tooling, and web services. My projects focus on making Revit add-ins easier to build, test, and maintain while applying the same attention to API design, diagnostics, and maintainability across backend systems.

## Revit and BIM

| Project | Purpose |
| --- | --- |
| [Revit Addin Manager](https://github.com/VolocyNazad/revit.addin-manager) | Pre-launch manager for Autodesk Revit `.addin` manifests: browse installed plugins across versions and scopes, toggle them on/off, and edit manifests before Revit starts. |
| [Revit Linter](https://github.com/VolocyNazad/revit.linter) | Extensible diagnostics and linting for Autodesk Revit models. |
| [Revit SDK](https://github.com/VolocyNazad/toolkit.revit.sdk) | Shared SDK and build infrastructure for libraries targeting multiple Revit versions. |
| [Revit Context](https://github.com/VolocyNazad/toolkit.revit.context) | Access to the active Revit application and document context. |
| [Revit Events](https://github.com/VolocyNazad/toolkit.revit.events) | Strongly typed infrastructure for working with Revit events. |
| [Revit Async](https://github.com/VolocyNazad/toolkit.revit.async) | Asynchronous execution through Revit external events. |
| [Revit Sugar](https://github.com/VolocyNazad/toolkit.revit.sugar) | Convenience APIs and extensions for common Revit development tasks. |
| [Revit Transaction Cache](https://github.com/VolocyNazad/toolkit.revit.transaction-cache) | Transaction-aware caching for Revit applications. |
| [Revit MediatR](https://github.com/VolocyNazad/toolkit.revit.mediatR) | MediatR integration for commands and requests executed in Revit context. |
| [Revit Templates](https://github.com/VolocyNazad/toolkit.revit.templates) | Project templates for creating Revit libraries and add-ins. |
